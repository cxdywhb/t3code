### 临期商品每日汇总测试用例

按上游验收口径，执行日 D 以北京时间确定，“7天内到期”为 [D, D+6]，含当天；到期字段按北京时间日期比较。同日到期商品顺序不限。以下用例均为待执行用例。

#### 用例 1：北京时间每日 09:00 触发与当日去重

- **前置条件**：服务器时区为 UTC；固定测试时钟；门店 A 有一件在当天及次日均满足筛选条件的在售商品；清空本次测试的触发与发送记录。
- **步骤**：依次推进至北京时间 2026-11-26 08:59、09:00、09:01，检查记录；同一天再次触发任务以验证去重；再推进至 2026-11-27 09:00。
- **预期结果**：08:59 不触发；当天 09:00 触发汇总并向 A 发送一次；09:01 不新增调度发送，同日重复触发不重复发送；次日 09:00 再发送一次。执行日期均按北京时间记录，服务器 UTC 时区不改变触发时刻。
- **复核证据**：测试时钟、调度时区配置、含门店及执行日期的触发记录、发送记录。按门店和北京时间日期统计，每天发送数为 1。

#### 用例 2：日期边界、在售筛选、排序与门店隔离

- **前置条件**：固定 D=2026-11-26；门店 A 商品如下，商品编号唯一。门店 B 另有 B1，为在售且于 11-28 到期。

| 商品 | 到期日（北京时间） | 状态   |
| ---- | ------------------ | ------ |
| A1   | 2026-11-25         | 在售   |
| A2   | 2026-11-26         | 在售   |
| A3   | 2026-11-29         | 在售   |
| A4   | 2026-12-02         | 在售   |
| A5   | 2026-12-03         | 在售   |
| A6   | 2026-11-29         | 非在售 |
| A7   | 2026-11-29         | 在售   |

- **步骤**：在北京时间当日 09:00 执行汇总，对照执行时商品快照逐条核对两家门店的结果。
- **预期结果**：A 仅包含 A2、A3、A7、A4，日期顺序为 11-26、11-29、11-29、12-02；A3 与 A7 相对顺序不限。A1、A5、A6 均不包含。B 仅包含 B1，两店数据互不混入。每份汇总可识别门店、商品及到期日。
- **复核证据**：执行时商品及状态快照、汇总内容、接收对象与门店的对应关系、发送记录；核对商品集合完全一致且日期非递减。

#### 用例 3：无匹配不发送且不影响其他门店

- **前置条件**：固定 D=2026-11-26。门店 A 仅有 11-25 到期的在售商品、12-03 到期的在售商品及 11-29 到期的非在售商品；门店 B 有一件 11-28 到期的在售商品。每轮使用独立测试环境或重置去重状态与记录。
- **步骤**：第一轮在当日 09:00 执行任务并核对两店发送记录；第二轮将 B 商品改为非在售，使全部门店无匹配，再执行任务。
- **预期结果**：第一轮 A 对应接收对象发送数为 0，B 为 1 且仅包含其匹配商品；第二轮全部接收对象发送数为 0。两轮均不发送空列表或“无商品”通知。
- **复核证据**：两轮执行时商品快照、任务执行完成记录及完整发送记录；确认零发送来自无匹配，而非任务未执行或发送失败。
